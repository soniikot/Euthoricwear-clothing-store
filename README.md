A clothing website built with React.JS and Redux. This project is a work in progress.


## Project Overview

This project is a clothing website that allows users to browse and purchase various clothing items. It is built using React.JS and Redux for state management. The project is currently under development and more features are being added.

## Features

- Browse clothing items
- Add items to the shopping cart
- View and manage the shopping cart
- Responsive design for mobile and desktop
- Checkout process and payment intregration
- User authentication 
- Product search and filtering 
- Add items to favourite products
